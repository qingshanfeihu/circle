# Design history

Working documents from the design of the interface. They are kept as a record of why the rules are what they are. They are not the current rules: those are in [The TUI contract](../tui-contract.md).

Open the HTML files in a browser. Each is a single self-contained page.

| File | What it is |
|---|---|
| [2026-09-29-tui-interaction-contract-draft.html](2026-09-29-tui-interaction-contract-draft.html) | The draft of the interaction contract: the evidence from the code, what eight comparable products do, the zoning rules, the display rules and the order of work. The implemented contract follows it, with changes made after trying it in a terminal. |
| [2026-09-29-tui-redesign-mockup.html](2026-09-29-tui-redesign-mockup.html) | A first mockup at 96 columns: one frame, the input box turning into the approval box, the plan folded into one line. Superseded by the draft above the same day. |
